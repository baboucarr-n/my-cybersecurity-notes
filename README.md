# My Cyber Notes

Personal notes from studying cybersecurity fundamentals -- Linux, networking, troubleshooting, and HTB/lab work. Started February 2026, still growing.

## Why This Exists

Started out scattered across OneNote, Obsidian, and Logseq. Pulled it all into one place so it's actually usable and easy to reference later, instead of hunting across three different apps.

## Structure

- `01-fundamentals/` -- core Linux concepts and commands
  - `01-core-concepts/` -- terminology, basic ideas
  - `02-filesystem-and-operations/` -- file system, cp, mv, which
  - `03-file-viewing-and-paging/` -- cat, head, more, less, nl, tail
  - `04-text-processing-and-search/` -- grep, find, sort
  - `05-system-admin/` -- system info, package management, installing software
  - `06-shell/` -- command line basics

- `02-networking/` -- networking concepts (still filling this in)

- `03-labs-and-htb/` -- HackTheBox notes and lab writeups

- `02-troubleshooting/` -- real problems I ran into and how I fixed them

- `04-parrot-security/` -- Parrot OS specific notes and tooling (in progress)

- `05-knowledge-base/` -- open questions, quick reminders, things I don't want to forget

## Notes on This Repo

- Every command example uses a placeholder name (`theFileName`) unless it's a real example from the original source.
- Where a note leans heavily on an outside source (Linux Journey, LabEx, HackTheBox Academy), I've credited it at the bottom.
- Some folders are still thin -- I'm adding to this as I actually study the material, not backfilling content I haven't covered yet.
